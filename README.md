# Инструмент визуализации графа зависимостей

## Общее описание
CLI-приложение для анализа зависимостей пакетов Python (pip).
Вариант №25. На данный момент реализованы **Этапы 1 и 2**:
настройка параметров через командную строку и поиск 
прямых зависимостей пакета.

## Описание функций и настроек
Программа принимает следующие аргументы командной строки:
- `--package` — имя анализируемого пакета (обязательный).
- `--repo` — путь к файлу тестового репозитория (обязательный).
- `--test-mode` — флаг включения режима тестирования (необязательный).
- `--version` — версия пакета (обязательный).
- `--ascii-tree` — флаг вывода в формате ASCII-дерева (необязательный).
- `--depth` — максимальная глубина анализа (обязательный, целое число).

## Команды для сборки и запуска
Для работы программы не требуется установка сторонних библиотек.
Запуск осуществляется через Python 3:

```bash
python src/main.py --package my-awesome-package --repo ./tests/test_package.txt --test-mode --version 1.0 --depth 3
